# Sports Analytics Platform

## Visão

Construir uma plataforma de Inteligência Esportiva focada inicialmente nas principais ligas europeias.

O produto será composto por uma plataforma de dados, modelos de Machine Learning, dashboards analíticos e APIs para consumo das previsões.

O Machine Learning é um componente da plataforma, não o produto em si.

---

# Objetivos do MVP

O MVP deverá ser capaz de prever:

- Probabilidade de Vitória
- Probabilidade de Empate
- Probabilidade de Derrota
- Placar mais provável
- Quantidade esperada de gols


Além disso disponibilizar:

- Dashboards Analíticos
- API REST
